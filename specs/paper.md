# Paper Spec: arXiv Preprint

## Intent

Port the main article (`results/article/article.html`) to LaTeX for submission to arXiv as a preprint. The paper should be a faithful conversion of the article's content, structure, and figures. Deviations from the article are documented below as section-level overrides. When the article and this spec conflict, this spec takes precedence.

Some HTML-specific features (collapsible sections, interactive elements, callout box styling) may not transfer cleanly to LaTeX. See decisions below.

## Build

Requires [Tectonic](https://tectonic-typst.github.io/tectonic/), a self-contained TeX engine that auto-downloads packages on demand. Install: `brew install tectonic`.

Compile:

```bash
uv run python -m scaling_law_analysis.paper.build
```

Source files live in `results/paper/` (paper.tex, references.bib). Output PDF is `results/paper/paper.pdf`. Build script is `src/scaling_law_analysis/paper/build.py`.

## References

### Source of truth

All references originate from reviewed metadata in `docs/references/references.yaml`, including full ordered authors, title, year, source type, venue, persistent identifiers, versioned source URLs, and verification provenance. Generate `results/paper/references.bib` and both HTML reference lists with `uv run python -m scaling_law_analysis.references`; never populate BibTeX independently. The same command refreshes article citation numbers by stable key. Metadata retrieval is separate from offline builds.

The canonical author list is complete. HTML abbreviates after three authors; BibTeX abbreviates after ten with an explicit `and others`, so large collaborations do not dominate the printed bibliography. Titles retain their capitalization and author names retain accents and name particles. Use `--check` to reject drift. Paper and submission builds check references before compiling.

### Inline hyperlinks

The article contains a small number of bare hyperlinks that are not formal references (e.g., a link to a Karpathy tutorial, a link to the derivation PDF on GitHub). In the paper, convert these to footnotes using `\footnote{\url{...}}`.

## Figures

Figures are generated by `src/scaling_law_analysis/article/figures.py` into `results/article/figures/`. The paper references PDF figures via relative paths. `uv run python -m scaling_law_analysis.paper.submit` creates a source archive with local figure paths and a freshly compiled `paper.bbl`. Compile the extracted archive independently before submission. Preserve existing dated submission archives.

## Collapsible Sections

The article uses HTML `<details>` elements for collapsible raw-data tables. In the paper, move these to the appendix.

## Appendix Exclusions

The following raw data tables from the article's collapsible sections are excluded from the paper appendix (the corresponding figures are sufficient):

- Extrapolation Error Raw Data
- Compounding Errors Raw Data
- Method Comparison Data (parameter recovery and exponent inference tables)
