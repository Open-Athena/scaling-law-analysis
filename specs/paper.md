# Paper Spec: arXiv Preprint

## Intent

Port the main article (`results/article/article.html`) to LaTeX for submission to arXiv as a preprint. The paper should be a faithful conversion of the article's content, structure, and figures. Deviations from the article are documented below as section-level overrides. When the article and this spec conflict, this spec takes precedence.

Some HTML-specific features (collapsible sections, interactive elements, callout box styling) may not transfer cleanly to LaTeX. See decisions below.

## Build

Requires [Tectonic](https://tectonic-typst.github.io/tectonic/), a self-contained TeX engine that auto-downloads packages on demand. Install: `brew install tectonic`.

Compile:

```bash
uv run python -m scaling_law_analysis.paper.build
```

Source files live in `results/paper/` (paper.tex, references.bib). Output PDF is `results/paper/paper.pdf`. Build script is `src/scaling_law_analysis/paper/build.py`.

## References

### Source of truth

All references originate from reviewed metadata in `docs/references/references.yaml`, including complete ordered authors, title, year, source type, venue, persistent identifiers, source URLs, and verification provenance. Run `uv run python -m scaling_law_analysis.references` to generate `results/paper/references.bib`, both HTML reference lists, and article citation numbers by stable key. Builds use offline metadata; `--check` rejects stale outputs and inconsistent citation targets. Paper and submission builds run this check before compiling.

The canonical author lists are complete. HTML abbreviates after three authors; BibTeX abbreviates after ten with an explicit `and others`. Preserve title capitalization, accents, name particles, and collective authors. Keep `natbib` citation punctuation explicit so the source archive retains the same citation style when its compiled `.bbl` is included directly.

Citation maintenance is limited to citations, bibliography metadata, and their generated artifacts and validation. Changes to authored prose, equations, table values, figures, captions, or conclusions require the author's explicit approval. Discuss proposed substantive corrections in chat before applying them.

### Inline hyperlinks

The article contains a small number of bare hyperlinks that are not formal references (e.g., a link to a Karpathy tutorial, a link to the derivation PDF on GitHub). In the paper, convert these to footnotes using `\footnote{\url{...}}`.

## Figures

Figures are generated by `src/scaling_law_analysis/article/figures.py` into `results/article/figures/`. The paper references these via relative paths (e.g., `../article/figures/figure_name.png`). No figure copying is needed; arXiv submission will be PDF-only.

## Collapsible Sections

The article uses HTML `<details>` elements for collapsible raw-data tables. In the paper, move these to the appendix.

## Appendix Exclusions

The following raw data tables from the article's collapsible sections are excluded from the paper appendix (the corresponding figures are sufficient):

- Extrapolation Error Raw Data
- Compounding Errors Raw Data
